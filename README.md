# RoboMaster Infantry Robot Control System

一个基于 STM32 HAL 库的 RoboMaster 步兵机器人综合电控系统实现。

## 📋 功能特性

### 核心功能
- **底盘控制**: 4 轮全向轮 X 型配置运动
- **云台控制**: 2 轴 (Yaw/Pitch) 云台控制，带角度限位
- **电机控制**: 基于 PID 的闭环电机速度调节
- **输入系统**: 键盘模拟遥控输入
- **安全保护**: 电机堵转保护、角度限位、紧急停止

### 底盘工作模式
1. **独立模式** (CHASSIS_MODE_INDEPENDENT): 底盘与云台独立运动
2. **小陀螺模式** (CHASSIS_MODE_SPIN): 底盘自旋，云台保持方向
3. **跟随模式** (CHASSIS_MODE_FOLLOW): 底盘跟随云台旋转对齐

### 云台特性
- Yaw 轴: ±180° 旋转范围
- Pitch 轴: -20° 到 +30° (带机械限位)
- PID 闭环控制
- 平滑角度插值

## 🎯 系统架构

```
主控任务调度 (1kHz)
├── Remote_Update()      → 输入处理 (防抖)
├── StateMachine_Update() → 状态转换
├── Chassis_Update()      → 底盘运动学 + 电机 PID
├── Gimbal_Update()       → 云台角度 PID 控制
└── LED_Update()          → 系统状态指示

硬件层
├── GPIO: LED (L1, L2) + 按键 (KEY1, KEY2, KEY3)
├── PWM: 电机驱动信号
└── 传感器: 编码器反馈 + IMU 陀螺仪
```

## 🔧 硬件要求

### 微控制器
- STM32F4xx 系列 (如 STM32F407VG)
- 主频: 84 MHz
- Flash: ≥512 KB, RAM: ≥64 KB

### 电机与传感器
- 底盘: 4× 直流霍尔编码器电机
- 云台: 2× 直流电机 (Yaw/Pitch)
- IMU: 6 轴 (陀螺仪 + 加速度计)

### 外设接口
- UART: 调试/数据传输
- GPIO: LED 指示灯、按键输入
- PWM 定时器: 电机 PWM 控制
- 硬件定时器: TIM6 (1kHz 控制) + TIM7 (LED 控制)

## 🎮 控制参数

### PID 参数
- **底盘电机 PID**: Kp=10, Ki=0.5, Kd=2
- **云台 PID**: Kp=15, Ki=0.3, Kd=5

根据实际电机特性调整。

### 底盘运动学参数
- 轮半径: 76 mm
- 轴距 (长): 400 mm
- 轮距 (宽): 400 mm
- 配置: X 型全向轮

### 云台限位
- Yaw: -180° ~ +180°
- Pitch: -20° ~ +30°

## 🕹️ 使用方法

### 按键功能
- **KEY1**: 切换机器人状态 / 小陀螺模式 / 跟随模式 (长按)
- **KEY2**: 云台 Yaw 角度增加 (每按一次 +5°)
- **KEY3**: 云台 Pitch 角度增加 (每按一次 +2°)

### LED 指示灯
- **L1** (呼吸灯): 系统运行指示
  - 呼吸效果 = MCU 正常运行

- **L2** (闪烁):
  - 1 Hz (1 秒一闪): 独立模式
  - 2 Hz (0.5 秒一闪): 小陀螺模式
  - 3 Hz (快速闪烁): 跟随模式

✅ 电机输出限幅 (±1000 PWM)

## 📊 底盘运动学

### X 型全向轮配置
```
      Front (Y+)
        ↑
M2 (FR) | M1 (FL)
    ╲   |   ╱
──────╲─┼─╱────→ Right (X+)
    ╱   |   ╲
M4 (BR) | M3 (BL)
        ↓
      Back (Y-)

运动学方程 (逆解):
M1 = Vx - Vy - (L+W)·ω
M2 = Vx + Vy + (L+W)·ω
M3 = Vx + Vy - (L+W)·ω
M4 = Vx - Vy + (L+W)·ω
```

其中:
- Vx: 前后速度 (mm/s)
- Vy: 左右速度 (mm/s)
- ω: 角速度 (rad/s)
- L: 轴距的一半
- W: 轮距的一半

## 🐛 常见问题排查

### 电机无反应
1. 检查 PWM 定时器配置和频率
2. 验证电机编码器连接
3. 审视 PID 参数和标定
4. 检查电机堵转保护状态

### 云台抖动
1. 逐步降低 Kp 或 Ki 值
2. 检查传感器滤波
3. 验证 IMU 标定和方向
4. 增加 Kd 提供阻尼

### 控制任务延迟或抖动
1. 确认 1kHz 定时器中断正常
2. 分析主循环��码执行时间
3. 降低外设 I/O 频率
4. 检查中断优先级冲突

### 键盘输入无效
1. 验证 GPIO 上拉配置
2. 检查防抖时间设置
3. 用 LED 直接测试 GPIO
4. 验证按键电气连接

## 💡 实现要点

1. **运动学**: 标准 X 型全向轮配置
2. **PID**: 带防积分饱和的标准 PID
3. **控制频率**: 固定 1 kHz，实时性好
4. **状态机**: 简单两态 (停止/正常) 保证安全
5. **防抖**: 20 ms 防抖 + 500 ms 长按检测
6. **中断驱动**: 所有控制逻辑在定时器中断中运行
